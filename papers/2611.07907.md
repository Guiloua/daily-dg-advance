# Log-concavity and level set curvature estimates for the first Dirichlet eigenfunction in hyperbolic space

对截面曲率−1的双曲空间内有界光滑严格horo凸域，第一正Dirichlet特征函数u的v=−logu在全域Hessian正定，且所有0<t<maxu的等值面光滑闭合。按{u>t}外法向取主曲率，n=2时等值曲线曲率K≥min∂Ωκ>1，n=3时外在曲率K≥min∂Ω(κ1κ2)>1；n≥4时每个等值面最小两条主曲率之积κ1κ2>1，因而总乘积K>1。推论1.2、1.4把Hessian正定扩展到边界主曲率≥1的有界光滑horo凸域，无直径限制。
