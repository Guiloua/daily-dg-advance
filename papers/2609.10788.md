# The Nieuwland number of the Octahedron

- **作者：** Jakob Steininger、Sergey Yurkevich

**完成的工作**

确定正八面体 Nieuwland 数为 3√2/4，并排除外投影为六边形的一类 Rupert 构形。

**使用技术**

- 多面体投影
- 几何极值
- 初等估计

**可能的突破**

把具体穿孔极值问题化为精确常数。

**限制与不确定性**

不直接解决其他多面体的 Rupert 问题。 当前为摘要级分析，方法及结论须回查原文。

**排序理由**

凸多面体极值结果具体，但与曲率主线联系有限。

**原始英文摘要**

We prove that the Nieuwland number of the Octahedron is $3\sqrt{2}/4$\. Along the way, we provide an elementary proof that Rupert's problem for the Octahedron admits no solution in which the outer projection is a hexagon\.
