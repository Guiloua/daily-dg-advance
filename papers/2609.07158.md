# The capillary $L_p$ dual Minkowski problem for $p&gt;q$ in higher dimensions

- **作者：** Ya Gao
- **arXiv：** [2609\.07158](https://arxiv.org/abs/2609.07158) · [PDF](https://arxiv.org/pdf/2609.07158)
- **分类：** math\.AP、math\.DG
- **进展类型：** 新方法/构造
- **阅读优先级：** 80/100 · 高优先级
- **分析深度：** 已补读正文关键部分

**完成的工作**

解决高维锐接触角下 p&gt;q 的毛细 Lp 对偶 Minkowski 问题的光滑存在唯一性。

**使用技术**

- Monge–Ampère 方程
- Robin 边界
- 新二阶辅助函数

**可能的突破**

针对高维边界二阶估计建立关键控制。

**限制与不确定性**

需 p&gt;q、n≥3 和锐角，边界端点情形不包含在内。 已补读所列正文片段；这不是逐行独立证明审查。

**排序理由**

非线性曲率方程与边界估计可复用。

**原始英文摘要**

We prove existence and uniqueness for the capillary $L_p$ dual Minkowski problem for $p&gt;q$ and contact angle $θ\in (0,\fracπ{2})$ in $\mathbb{R}^{n+1}$, $n\geq 3$\. We reduce it to a Monge-Ampère type equation with a Robin boundary condition on the unit spherical cap, by building a new auxiliary function to obtain the $C^2$ estimate for $p&gt;q$ in $\mathbb{R}^{n+1}$ \($n\geq 3$\), we then prove that there exists a unique smooth solution that solves this problem provided $θ\in (0, \fracπ{2})$\.
