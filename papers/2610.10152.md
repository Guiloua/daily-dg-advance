# The centered logarithmic Brunn--Minkowski inequality

作者的 Theorems 1.1–1.5 宣称 centered log-Brunn–Minkowski/log-Minkowski、cone-volume ambiguity 与 p>0 的 Lₚ inequalities。证明以 Ψ(C)=minξ∫C exp(−〈ξ,x〉)dx，在全部 Wulff support 上建立 log Ψ concavity；moment coordinate 中去除 affine function 的 variance estimate 与 retained matrix remainder 用于等号。
