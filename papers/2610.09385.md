# The higher dimensional affine Bernstein and Plateau problems

Theorem 2.1 构造 n≥10 的 entire smooth convex nonquadratic affine-maximal solution，以既有 singular cone 支撑 fourth-order ODE 的 global smooth solution；Theorem 2.2 在具有正 δ 的 scaling 或 x·Du growth 条件下证明全维 quadratic rigidity。Plateau 正则性以 secondary penalization、dual estimate 和 strict convexity 为核心。
