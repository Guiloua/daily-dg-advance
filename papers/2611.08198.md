# A diameter-one set in $\mathbb{R}^5$ that cannot be covered by six diameter-one balls

在带Frobenius度量的五维无迹实对称3×3矩阵空间中，作者取 p(u)=(uuᵀ−I/3)/√2（u∈S²），得到直径恰为1的紧Veronese曲面V。定理1证明V及其满维凸包均不能由六个闭半径1/2球覆盖，因而Grünbaum球覆盖常数g₅≥7；推论2还给出直径1的有限子集，六个闭半径0.50001球仍不能覆盖。证明将球截面的逆像包入六对对跖球面椭圆，通过Euler计数构造十二个五点球面凸包，再用每个面积严格小于π/3推出矛盾。
