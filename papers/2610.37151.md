# Rigidity of Constant-Scalar-Curvature Ricci Shrinkers with Totally Geodesic Focal Set

已核对 Theorems 1.1–1.2 与 Corollary 1.1：完备连通梯度 shrinker 满足 Ric+Hess f=½g、标量曲率常数，归一化 |∇f|²=f 后，以最低集 M₋=f⁻¹(0) 为焦集。若 M₋ 全测地，则孤立子 rigid，万有覆盖等距于 Nᵏ×Rᵐ，其中 N 紧、单连通且 Ric_N=½g_N。新论证处理 R=k/2、k,m≥2，其余允许标量值由既有刚性结果补齐，允许任一乘积因子维数为零。作者先从孤立子恒等式和完备性建立焦集光滑、紧、连通，r=2√f 为到 M₋ 距离，法指数映射 νM₋→M 为微分同胚。
