# Using Transformers to Generate 3-Manifold Triangulations

用脱水签名编码三维流形三角剖分，训练 GPT-2 风格 Transformer 生成剖分。主要训练各约3 exaFLOPs，覆盖2亿参数配6000万球面剖分至1100万参数配11亿剖分。最佳模型有10层、宽640，生成闭三维流形签名的比例为6.9%，其中82%为球面。对15个四面体的三维球面剖分，在6至3000 petaFLOPs预算下观察缩放行为，参数缩放指数估计0.49，统计区间[0.48,0.50]及系统误差±0.02，最优训练比约每参数234个token。另有低度数边计数实验。
