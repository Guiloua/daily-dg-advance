# Property $P_{\text{naive}}$ for non-orientable big Mapping Class Groups

- **作者：** Jesús Hernández Hernández、Tianyi Lou
- **arXiv：** [2609\.06110](https://arxiv.org/abs/2609.06110) · [PDF](https://arxiv.org/pdf/2609.06110)
- **分类：** math\.GR、math\.GT
- **进展类型：** 推广/加强
- **阅读优先级：** 54/100 · 中优先级
- **分析深度：** 摘要级分析

**完成的工作**

给出大映射类群子群的 P\_naive 判据，经定向双覆盖应用到不可定向无限型曲面。

**使用技术**

- 定向双覆盖
- 映射类群作用

**可能的突破**

扩展已有可定向群性质的适用范围。

**限制与不确定性**

需核对判据的子群假设，并非所有无限型映射类群无条件成立。 研究结论按摘要级分析；未完成正文方法核验。

**排序理由**

低维群论方向的专项推广。

**原始英文摘要**

We give a criterion for property $P_{\text{naive}}$ for subgroups of orientable big mapping class groups and apply it to mapping class groups of non-orientable infinite type surfaces through the orientation double cover\.
