# 读取性能与故障恢复

- 公开 reports / volume 成功响应：`public, max-age=60, must-revalidate`。错误和所有受保护响应：`no-store`。
- 日报与趋势状态独立。公开请求最长等待 15 秒，仅网络错误和 500/502/503/504 重试一次；超时、取消、其他状态及 JSON 错误不自动重试。
- 日期写入 URL，前进后退恢复筛选。切换时取消旧请求；失败保留实际已加载日期，不把旧内容标为新日报。
- 趋势接近可视区域 200px 才导入图表和读取 26 周；展开读取 104 周，组件生命周期内缓存成功结果。
- 静态正文直接渲染 HTML，摘要使用原生 details，无脚本仍可打开。原始 Markdown 链接直接指向同站点文件。
- 静态 JS/CSS 使用 SHA-256 内容指纹，趋势唯一请求为同站 `data/volume.json`；筛选索引和节点仅构建一次。
